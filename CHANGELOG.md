# Changelog

## Tauri 2 migration (preview)

- **Исправлено зависание SSH:** мост инициирует SSH ещё во время connection-flow (до появления xterm), буферизует вывод и переключает Redux в реальное состояние `succeeded` / `error`, включая отказ сервера, истечение времени ожидания и ошибку авторизации. Повторные попытки без команды пользователя блокируются.
- **Совместимость с современными серверами:** SSH-терминалы используют установленный системный OpenSSH через ConPTY/PTY с `StrictHostKeyChecking=ask` вместо libssh2, когда он доступен. Libssh2 остаётся запасным транспортом. UI, JS, CSS, шрифты и иконки сохранены побайтово.
- Живая проверка Windows Tauri на тестовом SSH-сервере, порт `2001`: OpenSSH получил host key и показал запрос подтверждения в xterm; ответ `no` корректно завершил сеанс ошибкой вместо бесконечного индикатора. Полная авторизация без подтверждения ключа и пользовательских данных не проводилась. SFTP/forwarding на libssh2 ещё требуют миграции KEX.

- **Исправлена стратегия переноса frontend:** Tauri загружает собранный HTML/React JavaScript/CSS и все 1353 неизменённых визуальных ресурса. Самописная Tauri страница удалена. Собран реальный Windows EXE; CDP проверил DOM и оригинальную тёмную тему.
- В Tauri добавлен отдельный совместимый bridge для bootstrap UI (офлайн local account reducer, Redux hydration, синхронные свойства Electron Window и базовая работа нативных кнопок окна). Ещё не подключён весь устаревший Electron IPC к системному Rust-бэкенду — функциональное совпадение с Electron пока неполное.


- GitHub Actions теперь собирает только Windows x64 portable EXE и macOS Apple Silicon DMG из tauri/; сборки Electron и macOS Intel из workflow удалены. Release публикуется только при наличии обоих файлов.
- Tauri 2 + Vite + xterm.js с интерфейсом Hosts/Keychain/SFTP/Logs/Settings и вкладками терминала. Rust использует ssh2 и portable-pty для SSH/SFTP и локальной оболочки.
- Добавлены проверка и явное доверие SHA256 fingerprint SSH host key, сохранение SSH-хостов вне Electron и базовые SFTP-операции без перезаписи файлов.
- Добавлены Serial/COM через кроссплатформенный `serial2` (доступные порты, скорость, data bits, parity, stop bits, flow control) и SSH Local TCP Port Forwarding через `ssh2` direct-tcpip (привязка к 127.0.0.1, проверка host key, ограничения подключений, запуск и остановка). Нужны интеграционные тесты с оборудованием и настоящим SSH-сервером.
- Добавлено переназначение 12 встроенных хоткеев в Settings → Shortcuts (запись Ctrl+V на Windows, сброс/очистка и локальное сохранение); для надёжного Copy/Paste интегрирован официальный `tauri-plugin-clipboard-manager`.
- Исправлены ошибочные вызовы JS в SFTP (ошибки и успешные передачи теперь отображаются корректно).
- Старые данные Electron не изменяются; синхронизация Docker, полный Keychain, dynamic/remote forwarding и остальные настройки/действия Electron пока не перенесены, релиз Tauri помечен preview.

## Native Rust / Rune (preview)

- Добавлено приложение на Rust с UI Rune (без Electron), единым кодом для Windows и macOS, шестью разделами Settings и редактируемыми сочетаниями клавиш.
- Добавлены нативные реализации SSH/PTY, SFTP, COM/Serial и клиент зашифрованной синхронизации AES-256-GCM + scrypt. Новый формат снимка не перезаписывает старые снимки Electron.
- Добавлены локальные профили, проверка SSH host key и отдельная CI-сборка нативного preview без замены стабильного релиза.
- Добавлена локальная интерактивная оболочка Windows ConPTY/macOS PTY; исправлена остановка сеанса и изоляция событий старых подключений.
- На сервере синхронизации добавлено атомарное условное создание `If-None-Match: *`, а Rust-клиент требует подтверждения поддержки этой возможности перед первой загрузкой.
- Терминал Rust/Rune получил прямой режим ввода клавиатуры (Ctrl+C, стрелки, F1–F12, Alt, Tab, Escape) и изменение размера активного SSH/ConPTY из настроек без переподключения; настройки размера совместимы со старыми профилями.
- Добавлен локальный SSH TCP port forwarding на `127.0.0.1` (до восьми соединений, проверка SSH host key, запуск и остановка из Rune UI); интеграционная передача трафика требует тестирования с реальным SSH-сервером.
- Терминал использует библиотеку `vt100` и Rune `Span` для нативной отрисовки ANSI 16/256/RGB, стилей, курсора, Unicode и alternate screen; добавлена история до 2000 строк и DECCKM для стрелок.
- SFTP через `ssh2`: создание папок, переименование и удаление с подтверждением; загрузка файлов использует `OpenFlags::EXCLUSIVE`, чтобы не затереть существующий файл даже при параллельных изменениях. Добавлены отображение прогресса в байтах и отмена передачи с очисткой неполных файлов.
- Добавлен защищённый импорт метаданных SSH-хостов из зашифрованных Electron-снимков `termius-portable-snapshot` v1: предпросмотр в Account, предупреждения, пропуск несовместимых конфигураций, сохранение существующих хостов и отдельная резервная копия Rust-профиля.
- Добавлен поиск по истории терминала с подсветкой совпадений и переходом между страницами `vt100`; тесты включают Unicode, ANSI-стили и alternate screen.
- Терминал Rust/Rune поддерживает до восьми одновременных SSH/PTY/Serial вкладок с отдельными экранами `vt100`, историей, вводом и поиском; закрытие и отключение затрагивают только выбранный сеанс. Добавлены переназначаемые хоткеи перехода и закрытия вкладок. Интеграционный тест запускает два реальных ConPTY и проверяет их независимость.
- Нативное выделение мышью (в том числе несколько строк) и `Copy selected` на основе встроенного механизма Rune; скролл истории колесом мыши. Вставка использует режим bracketed paste при запросе DECSET 2004 из `vt100`.
- Полностью обновлена реальная разметка Rune по присланным скриншотам: верхние Vault/SFTP/терминальные вкладки, левое меню, поисковая строка, карточки хостов и групп, правая панель Host Details, Keychain, Snippets, Known Hosts, Logs и отдельный экран Settings с шестью разделами.
- Доработано оформление непосредственно в Rune по референсам: плитки хостов и групп, компактная панель Host Details, групповой фильтр без лишней карточки All hosts, зелёные активные SSH-вкладки с настоящей кнопкой закрытия, векторные логотипы Debian/Ubuntu, начальное окно 1440×860. Группы и теги хостов сохраняются и фильтруются. Snippets имеют локальное редактирование/копирование/подтверждение удаления. Terminal по умолчанию занимает весь рабочий экран; дополнительные инструменты открываются через `⋯` без потери функций. Настройки Terminal включают 16 сохранённых цветовых схем, реально применяемых к консоли.



Актуальные изменения каждого релиза автоматически публикуются в GitHub Releases из коммитов после предыдущего стабильного тега. Начальная версия — `1.0.0`, обычный push повышает patch; minor/major можно задать вручную в workflow.

## 1.0.0

- Название **termian**, иконки Windows/macOS вместо Electron.
- Единый `app` для Windows x64 и macOS Intel / Apple Silicon.
- Постоянный локальный профиль без облачного аккаунта и командных экранов.
- Собственный Rust/Docker-сервер и ручная зашифрованная синхронизация с резервными копиями.
- Сохранение облачных настроек без возврата сохранённых секретов в интерфейс.
- Локальные Serial/COM-подключения.
- Ctrl+C / Ctrl+V на Windows; Ctrl+C без выделения остаётся прерыванием.
- Исправленный ввод и штатное сохранение данных хоста.
- Автосборка трёх платформенных пакетов, проверки и публикация релизов с changelog.
- Windows распространяется одним portable EXE без установки и ZIP; локальный профиль хранится в `termian-data` рядом с файлом.
- В настройках оставлены Account, Terminal, SFTP, Logs, Shortcuts, Version; исправлены ввод Ctrl+V и сохранение пользовательских переназначений на Windows.
