# Termian

SSH/SFTP-клиент на **Tauri 2**. Подключения и ключи хранятся локально; при необходимости данные можно синхронизировать через собственный сервер.

## Возможности

- SSH-терминал, вкладки, ключи и пароли, Known Hosts.
- SFTP (включая локальные файлы в панели Local), проброс портов и история подключений.
- Зашифрованные логи всего вывода терминальных сессий (хранятся 60 дней, очистка за час/день/неделю/всё) с тихим резервным копированием на свой сервер ([подробнее](tauri/README.md#логи-сессий)).
- Локальный Vault для хостов, ключей и настроек.
- Синхронизация зашифрованных данных со своим сервером между несколькими устройствами: изменения объединяются как в git, конфликты решает пользователь; автосинхронизация раз в час (отключается в настройках). Сервер ограничивает подбор токена.
- Автообновление из GitHub Releases с проверкой подписи: новая версия скачивается и устанавливается в фоне, перезапуск — по кнопке ([подробнее](tauri/README.md#автообновление)).

## Быстрый старт

Нужны Node.js, npm, Rust и [системные зависимости Tauri](https://v2.tauri.app/start/prerequisites/). На Windows также требуется WebView2.

```bash
git clone https://github.com/hahatulk/termius.git
cd termius/tauri
npm ci
npm run dev
```

## Сборка

Из каталога `tauri/`:

```bash
npm test
npm run check:web
npm run build:windows  # Windows x64
npm run build:mac      # macOS Apple Silicon
```

| Платформа | Формат | Статус |
| --- | --- | --- |
| Windows x64 | Portable EXE | Локальная сборка и запуск проверены |
| Windows x64 | Установщик NSIS (`-setup.exe`, для текущего пользователя) | Собирается в CI, запуск не проверен |
| macOS Apple Silicon | DMG | CI настроен, запуск на Mac не подтверждён |

Результаты сборки находятся в `tauri/dist/`. **Не удаляйте `tauri/dist/termian-data/`** — там хранится пользовательский профиль портативной версии. Установленная версия хранит профиль в `%APPDATA%` / `%LOCALAPPDATA%` (`app.termian.desktop`).
