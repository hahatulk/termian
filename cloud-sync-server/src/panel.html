Локальная панель сервера синхронизации

Вход паролем шифрования

Пароль проверяется расшифровкой снимка в памяти сервера и нигде не сохраняется. После серии неверных попыток вход временно блокируется.

Сервер

Снимок

Выгруженный файл не зашифрован: в нём пароли, приватные ключи и адреса хостов. Храните его в защищённом месте и удалите после использования.

Снимок

На сервере ещё нет снимка. Нажмите «Отправить» в клиенте Termian.

Справка

  • «Последняя синхронизация» — время последней отправки снимка клиентом («Отправить»). Получение («Получить») время файла не меняет и учитывается с момента запуска сервера.
  • Каждая отправка заменяет снимок целиком; предыдущие версии хранятся в revisions/ (последние 10).
  • Выгрузка — тот же JSON, что клиент импортирует при «Получить». Для переноса между устройствами используйте сам клиент, файл нужен для резервной копии и проверки содержимого.
  • Доступ с других адресов задаётся переменной SYNC_PANEL_ALLOWED_HOSTS (список имён/IP или *). Панель работает по HTTP: в чужой сети используйте HTTPS-прокси, VPN или SSH-туннель.
  • Неверный токен клиента блокирует его адрес после серии попыток; заблокированные адреса показаны в «Блокировки».
