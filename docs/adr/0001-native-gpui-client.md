# 0001. Нативный клиент на GPUI вместо WebView

- Статус: принято, переход в процессе
- Дата: 2026-11-13

## Контекст

Интерфейс legacy-клиента (`legacy/`) — скомпилированный React-бандл (~126 МБ, без исходников), работающий в WebView поверх Tauri. WebView расходует много памяти. Портировать бандл нельзя — интерфейс приходится писать заново.

## Решение

Новый клиент пишется на Rust с UI-фреймворком [GPUI](https://crates.io/crates/gpui) и живёт в корне репозитория (`Cargo.toml`, `src/`). Tauri-клиент перенесён в `legacy/` и остаётся релизным до паритета, после чего удаляется.

Рассмотренные альтернативы: egui (immediate mode, трудно повторить текущий визуальный стиль), Iced (стабильнее, но многословнее), Slint (декларативная разметка, лицензия GPL/коммерческая). GPUI выбран потому, что сделан под класс приложений «терминал + списки + вкладки» (редактор Zed) и даёт GPU-рендер.

## Последствия

- В репозитории временно два клиента; новые функции — только в нативном.
- Логика без окна (модели, ядро, миграция данных) — в библиотеке крейта и покрывается `cargo test`; отрисовку проверяем вручную.
- GPUI собран с `runtime_shaders`, чтобы не требовать полный Xcode (`metal`). Для релиза это нужно пересмотреть.
- Автообновление должно остаться совместимым с текущим ключом `plugins.updater.pubkey` и форматом `latest.json`, иначе установленные legacy-копии не перейдут на нативный клиент.
