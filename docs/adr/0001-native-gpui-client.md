# 0001. Нативный клиент на GPUI вместо WebView

- Статус: принято
- Дата: 2026-11-13

## Контекст

Интерфейс снятого с выпуска клиента — скомпилированный React-бандл (~126 МБ, без исходников), работающий в WebView поверх Tauri. WebView расходует много памяти. Портировать бандл нельзя — интерфейс приходится писать заново.

## Решение

Новый клиент пишется на Rust с UI-фреймворком [GPUI](https://crates.io/crates/gpui) и живёт в корне репозитория (`Cargo.toml`, `src/`). Клиент на Tauri удалён из рабочего дерева. Workflow собирает клиент на GPUI из корня репозитория.

Рассмотренные альтернативы: egui (immediate mode, трудно повторить текущий визуальный стиль), Iced (стабильнее, но многословнее), Slint (декларативная разметка, лицензия GPL/коммерческая). GPUI выбран потому, что сделан под класс приложений «терминал + списки + вкладки» (редактор Zed) и даёт GPU-рендер.

## Последствия

- Данные старого профиля macOS читаются через `src/legacy/`. Данные старого профиля Windows переносятся через облачный снимок.
- Логика без окна (модели, ядро, миграция данных) — в библиотеке крейта и покрывается `cargo test`; отрисовку проверяем вручную.
- GPUI собран с `runtime_shaders`, чтобы не требовать полный Xcode (`metal`). Для релиза это нужно пересмотреть.
- Нативный выпуск использует прежний ключ подписи и формат `latest.json`. Публичный ключ находится в `assets/app/update-public-key`.
